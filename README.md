## 🎯 <span style="color:#00E6E6;">Key Features</span>
- 🌑 Neon-dark themed project layout  
- 🖼️ Load and preview images with **OpenCV**  
- ⚡ Multiple filters implemented:
  - 🔹 Gaussian Blur  
  - ⚫ Grayscale  
  - 🔪 Edge Detection (Canny)
- 📊 Histogram visualization for:
  - Original image  
  - Blurred image  
  - Grayscale image  
  - Edge map  
- 🧪 Clean Jupyter Notebook workflow

## 🚀 <span style="color:#FF1493;">Getting Started</span>

### 1️⃣ Clone the Repository
```bash
git clone https://github.com/yourusername/Image-Processing-Histograms-Filters.git
cd Image-Processing-Histograms-Filters
```

### 2️⃣ Install Requirements
```bash
pip install -r requirements.txt
```

### 3️⃣ Run the Notebook
- Navigate to `notebooks/`  
- Open the `.ipynb` file  
- Execute cell-by-cell to:
  - Load images  
  - Apply transformations  
  - Plot histograms  
  - View output visuals
